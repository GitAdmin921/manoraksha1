# Training data

Add only ethically sourced, licensed, de-identified datasets here.

Recommended JSONL fields:
`text`, `language`, `intent`, `support_level`, `synthetic`

Example:
`{"text":"I feel overwhelmed and want to talk to someone.","language":"en","intent":"support_request","support_level":"elevated","synthetic":true}`

Never commit identifiable victim/survivor data, phone numbers, addresses, case notes, recordings or secrets to a public GitHub repository.
