# Privacy and safety

- Obtain meaningful consent before optional analytics.
- Support privacy lock to disable optional processing/sharing.
- Minimize data collection and retention.
- Mask personal identifiers according to role.
- Encrypt data in transit and at rest in production.
- Keep audit logs for privileged access.
- Never put identifiable survivor/victim data in a public GitHub repository.
- Emergency requests must route to an actual approved human support workflow.
- AI output is a support/risk signal, not a clinical diagnosis.
